# Food Delivery System — SQL Server

## 📌 Description
A relational database system for managing a food delivery platform.
It handles restaurants, customers, orders, payments, and deliveries.

## 🗃️ Database Tables
| Table | Description |
|-------|-------------|
| customer | Stores customer information |
| restaurant | Stores restaurant information |
| fooditem | Menu items for each restaurant |
| Orders | Customer orders |
| orderitem | Items inside each order |
| payment | Payment details for orders |
| delivery | Delivery tracking |

## 🔧 Files
| File | Description |
|------|-------------|
| DDL.sql | Creates all tables and relationships |
| INSERT.sql | Sample data for testing |
| Queries.sql | Views, Stored Procedures, Triggers, Indexes |
| ERD.png | Entity Relationship Diagram |

## 💡 Features
- Track active deliveries
- Monitor payment status
- Rank restaurants by revenue
- Customer order history
- Auto-update order status via Triggers
- Nonclustered Indexes for faster queries

## 🛠️ Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
